# ifandika.github.io
Maulana Ifandika

Use react 18 for stable and support legacy package

# Installation
First create a project.

Build project.
```BASH
$ npm run build
```

Run project.
```BASH
$ npm start
```

Deploy project.
```BASH
$ npm run deploy
```

# Dependency
- npm install react-type-animation
- mui
- react-router-dom
- react latex
